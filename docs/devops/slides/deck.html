Backups & Disaster Recovery

Stage 05 · Protect & Verify
< 5s
Verified Recovery Time
60s maximum target — our automated sandbox drill passes in under 5 seconds.
01 · Automated Daily Backups
Dedicated Alpine container runs every day at 02:00 UTC, compresses snapshots (.sql.gz), checks integrity, and keeps the newest 7 days.
02 · Safe Sandbox Verification
Running make dr-test creates an isolated test database, restores the latest backup, verifies every table, and cleans up without touching live data.
An untested backup is not a backup — every snapshot is proven restorable.
